minicrm VPS backup

minicrm VPS backup is a private tool operated by Zvi Naiman for the Jewish Points CRM (www.jewishpoints.com). It copies encrypted backups of the CRM database from the operator's server to the operator's own Google Drive account, so the data can be restored if the server fails.

The tool is not offered to the public and has no sign-up. It asks for Google's Drive "drive.file" permission, which lets it see, edit, create and delete only the specific Drive files that the user uses with this app.
